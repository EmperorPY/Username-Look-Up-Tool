# Username Lookup Tool

This is a Python project I made while learning Python.

- **What it does**

A Python program that uses APIs to check whether a username exists on Minecraft or GitHub and displays information about the account.

- **Features**

- Check if a Minecraft username exists
- Check if a GitHub username exists
- Display account information such as usernames, IDs, UUIDs and profile URLs

- **What I learned**

- How to use APIs with Python
- How to use `requests.get()` and HTTP status codes
- How to receive and use JSON data

- **How to run**

Download the files and run the Python file.

- **Made with**

Python

- **Future improvements**

- Add more services and APIs
- Turn the program into a website
